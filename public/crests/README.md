# Эмблемы клубов

Положите сюда PNG-файлы эмблем (желательно квадратные, с прозрачным фоном, от 256×256).
Если файла нет, игра показывает простую сгенерированную эмблему.

| Клуб | Имя файла |
|---|---|
| Реал Мадрид | `real-madrid.png` |
| Барселона | `barcelona.png` |
| ПСЖ | `psg.png` |
| Манчестер Сити | `man-city.png` |
| Ливерпуль | `liverpool.png` |
| Арсенал | `arsenal.png` |
| Бавария | `bayern.png` |
| Боруссия Дортмунд | `dortmund.png` |
| Интер | `inter.png` |
| Милан | `milan.png` |
| Ювентус | `juventus.png` |
| Атлетико Мадрид | `atletico.png` |

Имя файла задаётся полем `crest` у команды в `src/data/teams.json` — его можно поменять.
